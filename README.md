# OrkDev · releases

Este repositório guarda só os **instaladores do OrkDev** (Mac, Windows e Linux) e o arquivo `latest.json` de cada versão, que o app consulta para se atualizar sozinho. O código do OrkDev não fica aqui.

- **Baixar o OrkDev, conhecer o app e criar a sua conta:** https://orkdev.com
- Cada pacote é assinado. O app confere a assinatura antes de instalar.

---

**English.** This repository only holds the **OrkDev installers** (Mac, Windows and Linux) and each version's `latest.json`, which the app reads to update itself. The OrkDev source code is not here. Download the app and create your account at https://orkdev.com. Every package is signed, and the app checks the signature before installing.

**Español.** Este repositorio solo guarda los **instaladores de OrkDev** (Mac, Windows y Linux) y el `latest.json` de cada versión, que la app consulta para actualizarse sola. El código de OrkDev no está aquí. Descarga la app y crea tu cuenta en https://orkdev.com. Cada paquete está firmado y la app verifica la firma antes de instalar.
